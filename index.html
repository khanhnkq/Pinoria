Pinoria
Releases Source

Private and local-first

Download Pinterest media directly on your computer, with native-feeling controls.

Pinoria is a Manifest V3 extension for Chromium browsers. It helps you save Pinterest images, videos with audio, and animated media in original quality while keeping all processing inside your browser.

Get latest release Read on GitHub

Core features

One-click Quick Download

Hover or focus any pin on home, search, or board pages to reveal quick download controls. Save images, animated files, or MP4 video assets immediately.

Board and Section batch download

Use the board download control near the Pinterest board search area. Pinoria scans in batches, avoids duplicates, and shows visible scan and download progress.

Color-coded destination folders

Configure up to six destination folders under your Downloads directory. Each folder is mapped to a color so you can route media to the right location in one click.

How it works

1. Install from Releases

Download the latest packaged version from the repository Releases page, then extract the archive on your machine.

2. Load unpacked extension

Open chrome://extensions, enable Developer mode, click Load unpacked, and select the extracted folder that contains manifest.json.

3. Configure and download

Open the Pinoria popup, set your folder list and colors, then use quick download on pins or run a full board download.

Privacy and safety

Pinoria does not require an account and does not use analytics. Download and media handling stay local in your browser session. The extension requests only the permissions needed for downloads, storage, and Pinterest page integration.
